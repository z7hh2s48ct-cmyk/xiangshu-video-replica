# 三层乡村别墅视觉质量下限

检测到“三层乡村别墅 / 三层乡墅 / 农村三层自建房 / 乡村自建别墅”时，默认启用 `UPSCALE_RURAL_VILLA`。

## 默认 Scene Mode

`STRUCTURE_LOCK_STYLE_UPGRADE`：保留参考视频的机位、人物位置、建筑体量、大致空间结构和第一镜头叙事，同时允许升级立面材料、门窗、檐口、庭院、景观和完成度。

## 必须具备

- 轻高端改善型乡墅，不是普通廉价农村小楼。
- 三层关系清晰可见，建筑体量和比例成熟，不是简单叠三层盒子。
- 浅米白、暖灰等克制主色；石材、木色、深色金属等形成真实层次。
- 门窗尺度协调，深色铝合金窗框和真实玻璃，不做写字楼幕墙。
- 门廊、雨棚、退台、阳台、栏杆、檐口、排水、台阶等收口合理。
- 庭院铺装、草坪、灌木、景观树、步道或花池关系自然整洁。
- 有真实造价感与完成度，但仍属于中国乡村低密度居住环境。
- 真实建筑摄影，自然日光、真实材料纹理、正确透视、结构可建。

## 必须禁止

- 欧式城堡、宫殿、巨型罗马柱、金色堆砌、夸张门楼。
- 城市豪宅庄园、售楼处、酒店、办公楼、城市高层住宅感。
- 裸露水泥、廉价瓷砖满贴、蓝色反光玻璃、颜色杂乱。
- CG 效果图、塑料材质、过度锐化、过度商业渲染。
- 建筑比例错误、门窗随机、楼层结构不合理、庭院脏乱。

## 构图

默认中全景或中远景，三层主体必须可辨。若人物出镜，人物高度通常控制在画面约 35%–50%，避免人物占 70%–80% 导致建筑质量无法验收。
