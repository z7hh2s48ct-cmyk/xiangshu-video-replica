# 图生视频 Prompt 契约

最终 `image_to_video_prompt.md` 必须包含以下六个二级标题：

1. `生成目标`
2. `首帧一致性`
3. `全局风格与人物一致性`
4. `完整分镜时间轴`
5. `声音与口型策略`
6. `负面约束`

每个镜头必须明确：

- `start–end` 精确到毫秒级三位小数；
- 场景和主体；
- 人物动作；
- 摄影机运动；
- 人物与摄影机相对运动；
- `ON_CAMERA_SPEECH` / `VOICE_OVER` / `NO_SPEECH`；
- 是否需要口型同步；
- 实际逐字口播或画外音。

人物出镜镜头还必须包含：

- `动作来源：参考视频连续帧`、动作状态、置信度和至少两个证据时间点；
- 动作起始与动作结束；
- 人物移动路径和身体力学；
- 左右手分别做什么，无主动手势时也必须明确；
- 一个或多个带精确起止时间的动作阶段。

动作不得使用固定模板。参考视频出现走动、转身、手势或互动时不得降级为原地口播；参考视频明确静止时不得添加默认走路或默认手势。

一致性门：

- 所有 `run_manifest.json` 的镜头范围必须在 Prompt 出现。
- 所有 `spoken_segments[].text` 必须逐字出现。
- 首镜头必须从 `first_frame.png` 连续开始，不能重新设计人物或场景。
- 视频中的人物、建筑、服饰、门窗、庭院和光线不得无原因漂移。
- 负面约束必须包含人物、建筑、文字、UI、运镜和特效六类禁止项。
- 负面约束还必须禁止动作降级、动作发明、左右手混淆、动作起止丢失、下半身冻结、脚底滑动和手部畸形。
