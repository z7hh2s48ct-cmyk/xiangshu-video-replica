# 前后端页面功能与接口匹配梳理报告（v2 修订版）

> **版本说明**：v1 完成于 2026-09-18（基线 origin/main @ 1363de57）。v2 修订（2026-09-19）原因：① 用户已拍板新激活方案并确认 token 自动生成已实现，v1 中受旧激活码方案影响的结论需改判（详见 §0 修订注记，涉及 §1/§2/§3/§5/§7）；② 修订时 main 已前进至 e123292f，其中 #159（174f85ab）全量同步 OpenAPI 契约，v1 的 P3「generated/api.ts 类型漂移」已消除（§5 已销项）；③ v1 原文件在并行会话清理工作区时被删除，本版按最新口径重建。方法：脚本化前后端 API 全量双向 diff + 三路并行代码梳理（客户端 / 管理端 / 后端全景），关键结论均二次 grep 验证并标注 file:line。
> 配套文档：`docs/新激活方案落地任务书-注册建号与后台签发Token-2026-09-18.md`（v2，B/C/D 三个收尾任务）。

## 0. 结论摘要（TL;DR）

> **修订注记（取代 v1 同位置注记）**：用户拍板新激活方案——**客户自助注册建号 → 系统自动生成 Token（客户首次打开客户中心时自动初始化默认 token 并展示明文，`client/src/customer/CustomerCenterPage.tsx:150-160`）→ 不限设备台数 → token 仅作 API 调用凭证、不作登录凭证（选项 A）**。据此：① v1 的 P0「激活码管理 UI 不可达，需恢复 AdminActivationSection/ActivationCodesPage」**改判**：不恢复，激活码老流程（激活建号/首设备绑定/配对审批/管理端批次）转入退役任务（任务书 B，时机待运营确认）；② 「后台生成 token」指系统自动生成，**已实现，零开发**，不存在管理端签发缺口；③ 设备/会话管理入口仍需恢复（任务书 C），但设备 approve/replace-device 随配对审批退役、不接；④ 设备数容量检查未实装（migration 086 后 `users.max_devices` 无写入口、无比较逻辑），当前行为即"不限设备"，与新口径一致，需固化防回归（任务书 D）。

## 3. 业务链核查（六链，v2 口径）

### A. 准入链（注册→token→多设备）— **闭环，零开发（v2 重写）**
新方案已完整落地：自助注册建号+钱包（一事务）→ 首次打开客户中心自动初始化默认 token 并展示明文 → 密码登录任意设备（免审批、互不顶替、数量无上限）。激活码激活链（activate 建号+首设备+配对审批）功能完好但属旧方案，转退役任务。原 v1 断点②（首设备丢失卡配对）随配对审批退役消失；断点③（强制下线无入口）归任务书 C。

### B. 充值链 — 前向闭环，逆向缺失（维持 v1 结论）
下单→payment-code→回调验签→confirm_recharge_payment（幂等，先关单后付款可补入）→同事务入账 ✅。对账双通道（sync 仅 ZPay + 按客户按订单 reconcile 双通道）✅。**断点：退款闭环四层皆缺**（无接口/无 REFUNDED 态/无入口/调账 `1<=credits` 只增不减，admin_customer_routes.py:427）；REFUND_APPROVAL 是无生产者的空头枚举。**独立于激活方案，维持 P0**。

### C. 扣费链 — 闭环（维持 v1 结论）
预扣→SETTLE/RELEASE 同事务→UNCERTAIN 三层兜底→计费证据→报表。图片/ASR 已计费（billing_catalog.py:25-46）；利润报表 fen 新口径（#151）。小断点：`POST /api/control/first-frame-tasks/{id}/reconcile` 无前端入口（维持）。

### D. 发布链 — cancel/retry 闭环，sync 半断（维持 v1 结论）
账号→下单→publish_worker（lease+围栏）→cancel/retry/delete 完整。**断点：sync 只置 `sync_requested=1`（publish_records.py:476）无任何消费者**，按钮是无效动作。

### E. 会话与设备链 — 闭环
顶号已退役（互不顶替）；心跳租约/同设备重登 epoch+1/管理端 revoke/解绑踢会话均闭合。管理端强制下线接口在但 UI 孤儿（归任务书 C）。

### F. 公平队列 — 真实生效（维持 v1 结论）
QueueModeSection→queue-mode 设置→领取任务时公平轮转 vs 全局 FIFO 二选一（generation.py:5141）。
