## 0. 方案口径（已拍板）

1. **客户自助注册**（账号密码）→ 直接登录工作台。激活码不是获客入口。
2. **Token 系统自动生成**：首次打开客户中心自动初始化默认 token 并展示明文；之后可在 Token tab 自助轮换/吊销。无需管理端人工签发。
3. **不限设备台数**：任何设备密码登录即用，无配对审批，多设备会话并存互不顶替。
4. **Token 是 API 调用凭证**（选项 A）：登录通道 = 账号密码 + 设备凭据恢复，token 不用于登录。
